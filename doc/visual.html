visual.txt 适用于 Vim 9.2 版本。 最近更新: 2026年7月 VIM 参考手册 by Bram Moolenaar 译者: quhongjun 可视模式 Visual Visual-mode visual-mode 可视模式是一种灵活易用方式，可以为操作符选中一段文本。它也是选中文本列块的唯一 方式。 相关介绍请参考用户手册 04.4 一节。 1. 使用可视模式 visual-use 2. 进入和退出可视模式 visual-start 3. 改变可视区域 visual-change 4. 对可视区域执行操作 visual-operators 5. 列块操作 blockwise-operators 6. 重复 visual-repeat 7. 示例 visual-examples 8. 选择模式 Select-mode {自 Vim 7.4.200 起， +visual 特性始终启用}

1. 使用可视模式 visual-use

可视模式使用时分为三步: 1. 按 v 、 V 或 CTRL-V 标记文本起点。 将光标所在字符标记为文本起点。 2. 移动光标到文本终点。 从可视模式起点到光标所在字符间的文本 (含) 会被高亮。 3. 键入操作符命令。 高亮文本会执行对应操作。 'highlight' 选项可设置可视模式高亮的显示风格。 'virtualedit' 选项允许将光标定位到不存在字符的位置。 高亮文本缺省包含光标所在字符。但 'selection' 选项设为 "exclusive" 且光标刚好位 于选区之后时，则不包含光标所在字符。 使用 v 命令时，起点前、终点后的文本不会被高亮。但除 ~ 和 U 外， 所有的 大写和非字母操作符仍会作用于整行。参见下方操作符列表。 visual-block 使用 CTRL-V (列块可视模式) 时，高亮区域为起点到光标之间的一个矩形选区。部分 操作符仍会作用于整行 (见下方列表)。修改 ( c ) 和替代 ( s ) 操作会先删除高亮文 本，然后从选区左上角进入插入模式。

3. 改变可视区域 visual-change

v_o o 跳转到高亮选区的另一端 (Other): 将当前光标位置设为高亮 文本起点，光标跳转到选区另一端。选区范围实际保持不变。 v_O O 跳转到高亮选区的又一端。类似 "o" 命令，但列块模式下光 标会跳转到水平方向 (同一行) 的另一端。该端所在字符占用 多个屏幕位置 (如 <Tab>) 时，高亮选区可能发生变化。 v_$ 列块模式下使用 "$" 命令时，高亮选区右边界由选区最长行决定。一旦执行非纯上下方 向的移动命令，则该特性失效。 众多命令可移动选区终点。但是不能使用 Ex 命令，修改文本或放弃文件的命令。以下命 令 (包含以其开头的命令): "."、"&"、CTRL-^、"Z"、CTRL-]、CTRL-T、CTRL-R、CTRL-I 和 CTRL-O 会响铃并保留可视模式。 切换到同一缓冲区的另一窗口时，目标窗口内光标位置会自动调整以选中相同高亮选区。 特别适合在一个窗口查看选区起点，另一个窗口查看选区终点。此时可用鼠标右键 <RightMouse> (当 'mousemodel' 选项为 "popup" 时，应改用 <S-LeftMouse>) 拖动选 区任意一端。

5. 列块操作 blockwise-operators

提示: 开启 'virtualedit' 选项后，可在行尾之后或制表符中间位置设置列块的起点或 终点。 列块插入 v_b_I 对列块选区，执行 I{string}<ESC> 命令会在列块每行的块起始位置前插入 {string}。 仅对延伸至块范围内的行生效。过短的行不受影响。制表符会被拆分，保证视觉列对齐。 仅用于为文本行新增文本，不能删除文本。见 v_b_I_example 。 列块追加 v_b_A 对列块选区，执行 A{string}<ESC> 命令会在列块每行的块结束位置后追加 {string}。 当各行长短不一、导致块右边界不整齐时，存在以下几种不同行为: 1. 通过 <C-v>$ 创建的列块: 此时字符串追加到每行的行尾。 2. 通过 <C-v>{move-around} 创建的列块: 此时字符串追加到每行的列块末尾。必要时，自动填充空白字符补齐到块尾列。 见 v_b_A_example 。 备注: 对于未延伸至块范围的行，"I" 和 "A" 行为不同。这是有意的设计，满足不同编 辑需求。 仅用于为文本行新增文本，不能删除文本。见 v_b_I_example 。 列块修改 (c) v_b_c 列块内所有选中文本会被相同字符串替代。使用 "c" 命令时，先删除原有文本，然后进 入插入模式，此时键入文本 (不可换行)。按下 <Esc> 后，在所有原先选中行的相应位置 上会插入相同的键入文本。 列块修改 (C) v_b_C 类似 "c" 命令，但选区所有行上，会扩展选区到行尾。 v_b_< 列块平移 v_b_> 列块会按 'shiftwidth' 值平移。块右边界对平移量没有影响。右移操作会以块左边界决 定右移起始位置，空白填充会根据 'ts' 和 'et' 选项自动优化使用制表符。左移操作同 样会以块左边界作为左移终止位置。 见 v_b_>_example 。 见 v_b_<_example 。 列块替换 v_b_r 高亮选区内每个屏幕字符会被相同字符替换。制表符会被拆分，虚拟空白也会被替换，保 持屏幕布局不变。 见 v_b_r_example 。

6. 重复 visual-repeat

重复执行可视模式操作符时，操作符作用的文本长度与上次操作保持一致: - 行可视模式: 相同行数。 - 列块可视模式: 相同行数与列数。 - 单行字符 (普通) 可视模式: 相同字符数。 - 多行字符可视模式: 相同行数，末行沿用上次操作末行的字符数。 重复操作文本起点为光标位置。如果上次选区最后使用过 "$" 命令扩展高亮文本，则重 复操作同样会扩展到最长行的最右侧列。传入 . 命令的计数不生效。

8. 选择模式 Select Select-mode

选择模式外观类似可视模式，但可执行的命令差异很大，风格类似 Microsoft Windows 上的选区模式。开启 'showmode' 选项时，屏幕末行会显示 "-- 选择 --"。 进入选择模式的几种方法: - 鼠标选中区域，且 'selectmode' 选项含 "mouse"。'mouse' 必须包含当前模式对应的 标志位。 - 按下 Shift 键并同时键入非可显示光标移动命令，且 'selectmode' 选项含 "key"。 例如: <S-Left> 和 <S-End>。'keymodel' 选项也必须包含 "startsel"。 - 键入 v 、 V 或 CTRL-V 命令，且 'selectmode' 选项含 "cmd"。 - 在普通模式下，键入 gh 、 gH 或 g_CTRL-H 命令。 - 在可视模式下，键入 CTRL-G。 v_CTRL-G 选择模式下的命令如下: - 可显示字符、<NL> 和 <CR> 都会先删除选区文本并进入插入模式，然后插入该字符。 - 按下 Shift 键并同时键入非可显示移动命令，会扩展选区。'keymodel' 选项必须包含 "startsel"。 - 不 按 Shift 键并键入非可显示移动命令，会退出选择模式。'keymodel' 选项必须包 含 "stopsel"。 - ESC 会退出选择模式。 - CTRL-O 会临时切换到可视模式，执行单条命令。 v_CTRL-O - CTRL-G 切换到可视模式。 - CTRL-R {register} 指定键入文本时，存放被删除文本的寄存器。 v_CTRL-R 除非指定 "_" (黑洞) 寄存器，否则同时会覆盖无名寄存器。 其余按键逻辑同可视模式。 在选择模式下使用操作符时，如果使用行选区，虽然选中整行作为操作对象，但操作行为 等同于字符选区。例如删除整行后，粘贴时可在一行中间插入。 选择模式专用键盘映射和菜单 Select-mode-mapping 使用 :vmap 或 :vmenu 命令定义的映射和菜单，在可视模式和选择模式下都生效。 在选择模式下触发时，Vim 会自动切换到可视模式，确保行为与可视模式保持一致。如果 不希望如此，可用 :xmap (专用于可视模式) 或 :smap (专用于选择模式)，以及用 于菜单的 :xmenu 或 :smenu 。 一个特殊案例是: :vnoremap <C-K> <Esc> 该映射在可视模式下会结束可视模式，但在选择模式无效，因为执行完映射后，会自动恢 复选择模式。正确写法是: :snoremap <C-K> <Esc> 用户一般预期可显示字符会直接替换选区文本。因此应避免在选择模式下映射可显示字 符。或在执行 :map 和 :vmap 后，用 :sunmap 单独撤销选择模式下的映射。 映射或菜单执行完毕后，Vim 会自动重新激活选区并回到选择模式。但以下情况除外: 选 区被删除，缓冲区切换，或窗口布局发生变更。 键入字符触发删除选区并进入插入模式时，该键入字符会应用插入模式映射。这容易引起 混淆，因为选择模式输入的字符触发了插入模式映射。语言映射同样也会被应用。 gV v_gV gV 选择模式映射或菜单执行完毕后，不再自动选中选区。本命令 应放在映射或菜单命令末尾，或至少在所有选区操作之后。 gh gh 启动字符选择模式。类似 v 命令，但进入选择模式而非可 视模式。 助记: "get highlighted"。 gH gH 启动行选择模式。类似 V 命令，但进入选择模式而非可视 模式。 助记: "get Highlighted"。 g_CTRL-H g CTRL-H 启动列块选择模式。类似 CTRL-V 命令，但进入选择模式而 非可视模式。 助记: "get Highlighted"。 vim:tw=78:ts=8:noet:ft=help:norl:
