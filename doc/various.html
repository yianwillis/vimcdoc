:norm[al][!] {commands} :norm :normal 执行若干普通模式命令 {commands}。从而可在命令行上输入 并执行普通模式按键序列。{commands} 的执行效果如同键盘 输入。撤销时，会将所有命令作为一个整体撤销。 遇到错误即停止执行。 带 [!] 时，不使用按键映射。否则，即使本命令是在不可递 归映射 ( :noremap ) 中调用，其参数中的按键仍然可以使用 映射。 {commands} 必须是完整命令。如果命令未结束，最后一条会 被中止，如同按下了 <Esc> 或 <C-C>。这意味着插入命令 (如需进入插入模式，见 :startinsert ) 和 : 命令都必 须完整。也不能用 Q 或 gQ 启动 Ex 模式。 本命令执行期间，显示不刷新。 {commands} 不能以空格开头，确有需要时，可在前面加个计 数 1 (一)。"1 " 代表单个空格按键命令。 {commands} 执行时忽略 'insertmode' 选项。 本命令不能后跟其他命令。'|' 被认为是命令内容。 支持递归使用，递归深度上限由 'maxmapdepth' 决定。 另一种方法是通过 :execute 构造 :normal 的参数。它 以表达式作为参数，从而可用可显示字符来表示特殊字符。 示例: :exe "normal \<c-w>\<c-w>" :{range}norm[al][!] {commands} :normal-range 对 {range} 范围内的每一行执行若干普通模式命令 {commands}。执行前，光标先定位在每行首列。其余行为与不 带范围的 :normal 命令一致。 :sh :shell E371 :sh[ell] 启动外壳。外壳退出时 (执行完 "exit" 命令)，回到 Vim。 使用外壳命令名取自 'shell' 选项。 E360 注意: Amiga 上，由编译器以快速修复模式启动 Vim 时，本 命令不可用。因为编译器已将标准输入设为非交互模式。 :!cmd :! :!{cmd} 通过外壳执行 {cmd} 命令。另见 'shell' 和 'shelltype' 选项。过滤命令参见 :range! 。 Vim 按以下顺序，使用 'shell'、'shcf'、'sxq' 和 'shq' 选项构造命令行: `&sh &shcf &sxq &shq {cmd} &shq &sxq` 由此可见，虽然可同时设置 'sxq' 和 'shq'，但很少有用。 {cmd} 内部受 'sxe' 选项影响，可能需要额外转义。 此外，{cmd} 内所有 cmdline-special 特殊字符，在传给 外壳前会先由 Vim 替换。 E34 {cmd} 里的 '!' 会被替换为前次外部命令 (另见 'cpoptions')，但 '!' 前带反斜杠时，不进行替换，只移除 单个反斜杠。例如: 先执行 "!ls"，然后在执行 "!echo ! \! \\!" 时，实际会执行 "echo ls ! \!"。 {cmd} 里的 '|' 会传给外壳，而不会用于拼接 Vim 命令。见 :bar 。 {cmd} 里的 "%" 会被展开为当前文件名，"#" 会被展开为轮 换文件名。不转义文件名内特殊字符，必要时加引号以避免特 殊含义: :!ls "%" 文件名含 "$" 时，单引号效果更好，但文件名不能包含单引 号: :!ls '%' 以下写法始终有效，但需要输入更多内容: :exe "!ls " .. shellescape(expand("%"),1) 要使用按本义出现的 "%" 或 "#"，前面加上反斜杠。例如， 要列出所有以 "%" 开头的文件: :!ls \%* 换行符会终止 {cmd}，换行之后会被视作后续的 ":" 命令。 但如果换行前带反斜杠，则移除该反斜杠，{cmd} 继续接受参 数。无论换行前有多少个反斜杠都是如此，但仅移除一个反斜 杠。 Unix 上，命令通常在非交互外壳里运行。要改用交互式外壳 (例如需要别名机制 aliases)，可将 'shellcmdflag' 设为 "-ic"。Win32 上另见 :!start 。
