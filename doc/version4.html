'backup' 原先缺省开启。覆盖原文件时会生成备份文件。 现在缺省关闭。文件写入成功后，备份文件会被删除。如需保留备份文件，在 vimrc 开 启 'backup'。做出这项改动的原因是大量用户反馈遗留备份文件不符合 Vi 兼容行为。 备份文件后缀变更 backup-extension
备份文件原先后缀为 '.bak'。由于其他程序也使用该后缀，部分用户也会手动创建同名 '.bak' 副本，因此改为不常用的 '~'。另一个好处是后缀字符更短，适合文件名长度受 限的系统。例如在 MS-DOS，'longfile.c' 和 'longfile.h' 的备份都会变成 'longfile.bak'；修改后分别是 'longfile.c~'、'longfile.h~'。 如果仍想用 '.bak'，设置 'backupext': :set bex=.bak 交换文件结构变更 swapfile-changed
交换文件内部新增多项参数。Vim 会保存用户名以及正在编辑文件的相关信息，提升恢复 能力，同时标识交换文件来源。交换文件头部现在可以在不同字节序、不同 int 长度的 机器上解析。在这类机器尝试恢复文件时，会提示无法恢复。 受此改动影响，3.0 和 4.0 的交换文件不能互通。如果有 3.0 崩溃遗留的交换文件，请 用 3.0 恢复，不要使用 4.0。 swap-file "-w scriptout" 参数变更 scriptout-changed
'vim -w scriptout' 原本是追加写入录制文件。该行为不符合直觉，现在改为新建文 件。不会直接覆盖已有文件，防止依赖追加行为的用户丢失文件。 [该参数后续版本被移除] -w 退格键与删除键 backspace-delete
3.0 版本中在插入模式下，退格键和删除键都执行退格，删除光标左侧字符。 4.0 版本中，删除键行为改变，删除光标下方字符，和命令行的删除行为一致。光标在行 尾，且开启 'bs' 选项时，会合并两行。 <Del> i_<Del> 3.0 版本中固定退格定义为 CTRL-H，删除键定义为 CTRL-?。 4.0 版本中从 termcap 或 termlib 获取退格、删除键编码，并适配 Unix 的 "stty erase" 设置，适配不同键盘定义的擦除字符。 <BS> i_<BS> 如果希望插入模式退格、删除保持旧版行为，在 vimrc 添加: inoremap ^? ^H 也可以补充下面两行修正 <BS>、<Del>: set t_kb=^H set t_kD=^? (用 CTRL-V CTRL-H 输入 ^H，用 CTRL-V CTRL-? 或者 <Del> 输入 ^?) 如果 't_kb' 配置正确但 't_kD' 不对，执行 :fixdel 。该命令会根据 't_kb' 自动设 置 't_kD'，适合多终端切换场景。 :fixdel 当 ^H 不被识别为 <BS> 或 <Del> 时，缺省当作退格处理。 管道符 | 的转义规则变更 escape-bar
当 'cpoptions' 包含 'b' 标志位时，在映射与缩写命令中，反斜杠无法用来转义 '|'， 仅能使用 CTRL-V。这是为兼容 Vi。在 Vi 兼容模式下，映射里使用了 "\|" 来包含竖线 时，需要替换成 "^V|"。参见 :bar 。 按键编码变更 key-codes-changed

'errorformat' 现已支持多种格式，以逗号分隔。采用第一条成功匹配的格式。缺省值已 调整，可识别最常见的格式。 errorformat 某条格式内部包含逗号时，逗号前需要加反斜杠转义。需要写两个反斜杠，因为 :set 命令会消耗掉一个反斜杠。 移除 'graphic' 选项 graphic-option-gone
'graphic' 选项已移除。该选项原本用于让 <~> 与 0xa0 之间的字符直接在屏幕显示。 现在由 'isprint' 选项接管，能力更强。缺省行为保持不变；仅当曾在 vimrc 里手动设 置 'graphic '时才需要关注此项。 'isprint' 移除 'yankendofline' 选项 ye-option-gone
'yankendofline' 选项已删除。替代方案直接使用 :map Y y$ 'icon' 与 'title' 缺省值变更 icon-changed

'highlight' 的 'i' 标志位现在代表斜体高亮，不再是反转。'r' 标志位用于反转，也 就是原先 'i' 标志位的作用。此改动通常看不到差别，因为多数终端不支持斜体，此时 会回退到使用反转。 'highlight' 'highlight' 中未配置对应场景时，使用 'highlight' 缺省值的对应样式，而不是直接 使用反转。 'tildeop' 与 'weirdinvert' 简写变更 short-name-changed
'to' ('tildeop' 的简写) 换名成 'top'。 'tildeop' 'wi' ('weirdinvert' 的简写) 换名成 'wiv'。 'weirdinvert' 修改原因是，Vi 将 'wi' 用作 'window' 简写、'to' 用作 'timeout' 简写。如果继续 沿用旧简写，设置选项不会报错，但生效的是别的选项。 可视模式下 v、V、CTRL-V 的用法变更 use-visual-cmds
