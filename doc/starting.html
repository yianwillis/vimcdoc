5. $VIM 和 $VIMRUNTIME

$VIM 环境变量 "$VIM" 用于定位 Vim 的各种用户文件，包括用户启动脚本 ".vimrc" (译者注: 原文如此，逻辑上也无不妥，但该环境变量主要目的是 Vim 的安装目录)。具 体位置因系统而异，见 startup 。 为避免每位用户都要设置 $VIM 环境变量，Vim 会按以下顺序确定 $VIM 值: 1. 优先读取已定义的 $VIM 环境变量值。可用于强制 Vim 在指定目录下寻找支持文件。 示例: setenv VIM /home/paul/vim 2. 使用 'helpfile' 路径，但如果其中也包含其他环境变量 (缺省 "$VIMRUNTIME/doc/help.txt"，就会遇到先有鸡还是先有蛋的问题)，则不采用。随后 去掉文件名部分 ("help.txt" 或其他文件名)。再依次删除以下的末尾目录名: "doc"、"runtime" 和 "vim{version}" (如 "vim82")。 3. 对 Win32，Vim 会试图提取可执行文件目录名。以 "/src" 结尾时，也截去该段。此 逻辑适用于解压 .zip 压缩包，并调整搜索路径以找到 vim 可执行文件的情况。依次 删除以下的末尾目录名: "runtime" 和 "vim{version}" (如 "vim82")。 4. 对 Unix，采用编译时预设的安装目录 (见 :version 输出结果 "$VIM 预设值")。 Vim 仅进行以上操作一次，并据此设置 $VIM 环境变量。此后要修改该值，可用 :let 命令: :let $VIM = "/home/paul/vim/" $VIMRUNTIME 环境变量 "$VIMRUNTIME" 用于定位运行时支持文件，包含在线帮助文档和语法高亮脚本 等。例如，主帮助文档缺省路径是 "$VIMRUNTIME/doc/help.txt"。 通常无需自行设置 $VIMRUNTIME，Vim 自动按以下顺序解析: 1. 优先读取已定义的 $VIMRUNTIME 环境变量值，可用于指定特殊的运行时文件路径。 2. 目录 "$VIM/vim{version}" 存在时，使用该路径。{version} 为 Vim 不含 '-' 或 '.' 的版本号。例如: "$VIM/vim82"。这是 $VIMRUNTIME 常规值。 3. 目录 "$VIM/runtime" 存在时，使用该路径。 4. 直接使用 $VIM 值。用于后向兼容老旧版本。 5. 'helpfile' 选项已设置且不含 '$' 符号时，使用该路径，去掉末尾 "doc/help.txt" 部分。 对 Unix，编译时给出 $VIMRUNTIME 预设缺省值时 (见 :version 输出结果)，跳过第 2、3 和 4 步，第五步判断结束后直接使用编译预设值。这意味着编译缺省值优先于 $VIM 值。可用于 $VIM 为 "/etc" 而运行时文件位于 "/usr/share/vim/vim82" 的场 景。 Vim 仅进行以上操作一次，并据此设置 $VIMRUNTIME 环境变量。此后要修改该值，可用 :let 命令: :let $VIMRUNTIME = "/home/piet/vim/vim82" 需要在外壳里 (如对 Vim 帮助文档进行 grep 的脚本) 获取 $VIMRUNTIME 值 ，可用: VIMRUNTIME=$(vim -es '+put=$VIMRUNTIME|print|quit!') 不可将 $VIMRUNTIME 设为空值，会导致多项功能失效。
