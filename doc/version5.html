不 兼 容 点 incompatible-5

'compatible' 缺省值变更 cp-default
Vim 5.0 致力于更好地兼容 Vi。这方便将 Vim 直接替代 Vi 使用，但会造成部分行为与 4.x 版本不兼容。 4.x 版本中 'compatible' 选项缺省关闭。现在该选项缺省开启。最先会察觉到的是 'u' 命令撤销自身操作。其他连带影响包括映射行为改变甚至失效。 大量从 Vim 4.x 升级至 5.0 的用户会对此感到困扰，因此: Vim 检测到 vimrc 文件存 在时，自动关闭 'compatible'。这项特殊机制保证九成 Vim 用户不会被该改动影响。 具体影响是: - 要用兼容模式、且无 vimrc 文件，无需任何操作。 - 要用非兼容模式、且存在 vimrc 文件，无需任何操作。 - 要用兼容模式、且存在 vimrc 文件，可在 vimrc 文件最开头写入: :set compatible - 要用非兼容模式、且无 vimrc 文件，可选方案之一: - 创建空 vimrc 文件 (Unix 为 '~/.vimrc')。 - 在 .exrc 文件或 $EXINIT 中加入命令: :set nocompatible - 使用 -N 参数启动 Vim。 如果刚接触 Vi 和 Vim，强烈推荐开启 'nocompatible'。Vi 存在很多非预期副作用， 开启非兼容模式可以规避这些问题。参见 'compatible'。 如果需要部分兼容特性与部分非兼容特性，可通过 'cpoptions' 微调兼容行为。 当以 "ex" 或 "gex" 程序名调用 Vim 时，Vim 总是以兼容模式启动。 文本排版命令 "Q" 变更 Q-command-changed
Q 命令过去用于按 'textwidth' 指定宽度格式化文本行。该功能现在改为 gq 。改动 原因是， Q 是 Vi 标准命令，用于进入 Ex 模式；Vim 现已完整实现 Ex 模式。 如果仍想用 "Q" 执行格式化，添加映射: :noremap Q gq 如果同时需要保留原 "Q" 的功能: :noremap gQ Q 命令行参数变更 cmdline-changed
现在命令行的文件参数与选项参数可以混合使用，选项可以写在文件名之后。示例: vim main.c -g 编辑以 '-' 开头的文件时不能这样使用，此时用 "--" 参数 --- : vim -g -- -main.c -v 现在代表以 Vi 模式启动 Ex；只读模式改用 -R 。 旧版: "vim -v file" -v 新版: "vim -R file" -R -e 现在代表以 Ex 模式启动 Vi；快复模式改用 -q 。 旧版: "vim -e errorfile" -e 新版: "vim -q errorfile" -q Ex 模式下的 "-s" 现在代表静默 (批处理) 模式。 -s-ex -x 预留给加密功能；Amiga 平台用 -f 避免启动时新建 CLI。 旧版: 'vim -x file' -x 新版: 'vim -f file' -f Vim 最多支持十个 "+cmd" 与 "-c cmd" 参数。旧版只会执行最后一条。 -n 会覆盖 vimrc 内 'updatecount' 的设置，但不影响 gvimrc。 自动命令保留机制 autocmds-kept
5.0 之前: 事件、文件名匹配规则、命令完全相同的自动命令，仅能定义一次。简单自动 命令 (设置选项) 不受影响；但复杂场景下，同一条命令需要重复注册时，该限制会引发 问题。Vim 5.0 会保存全部自动命令，并严格按定义顺序执行。 最明显的副作用是，如果多次加载同一个 vimrc，其中的自动命令会重复注册。可任选下 面方法规避: - 定义前先清除已存在的同名自动命令。示例: :au! * *.ext :au BufEnter *.ext ... - 将自动命令包裹在 ":if" 判断中。示例: if !exists("did_ext_autocmds") let did_ext_autocmds = 1 autocmd BufEnter *.ext ... endif - 使用自动命令组，定义前清空组内规则 :augroup : augroup uncompress au! au BufReadPost *.gz ... augroup END 'hidden' 用法变更 hidden-changed
4.x 版本中，仅有部分命令会用到 'hidden' 选项。现在所有缓冲区从窗口里消失的命令 都会遵循该选项。 过去在已修改的缓冲区执行 ":buf xxx"，缓冲区就会转为隐藏。现在必须手动开启 'hidden' 选项才能实现该行为。 新逻辑更简洁: Vim 隐藏缓冲区与否，不再取决于执行的具体命令。 - 未置位 'hidden': 不会产生隐藏缓冲区。例外: :hide 、 :close !；极少数场景 中，不隐藏就会丢失缓冲区修改内容。 - 置位 'hidden': 几乎不会卸载缓冲区。例外: :bunload 、 :bdel 。 :buffer 现在支持感叹号 "!": 丢弃当前缓冲区的改动。 :bnext 、 :brewind 等命 令同样支持。 文本对象命令变更 text-objects-changed
文本对象命令启用新命名。此举可扩充更多文本对象，腾出单字符给其他可视模式命令。 可用单字符已耗尽，因此文本对象名称改为双字符，首字符固定为 'i' 或 'a'。 旧版 新版 a aw 一个单词 v_aw A aW 一个字串 v_aW s as 一个句子 v_as p ap 一个段落 v_ap S ab 一个 () 块 v_ab P aB 一个 {} 块 v_aB 另有一组以 "i" 开头的文本对象，代表 "内含" (inner)。选中范围和对应 "a" 对象一 致，但不包含空白。 X-Windows 资源移除 x-resources
Vim 不再支持以下 X 资源: - boldColor - italicColor - underlineColor - cursorColor Vim 现改用高亮组设置颜色，避免粗体字体附带固定颜色带来的混淆。参见 :highlight 与 gui-resources 。 $VIM 的用法 $VIM-use
Vim 现通过 VIM 环境变量查找全部系统文件，包括全局 vimrc、gvimrc、menu.vim、联 机帮助与语法文件。参见 $VIM 。5.4 版本起，也可使用 $VIMRUNTIME 。 Unix 平台执行 "make install" 时，Vim 会自动设置 $VIM 缺省值。 如果未设置 $VIM，缺省值取自 'helpfile' 的目录但去掉末尾 "/doc/help.txt"。 MS-DOS 与 Win32 $HOME 的用法 $HOME-use
MS-DOS 和 Win32 版 Vim 在查找 vimrc 或 exrc 文件、读写 viminfo 文件时，现优先 读取 $HOME。旧版在这些平台使用 $VIM，多用户环境下会引发问题。现在仅当未设置 $HOME 或目标文件在 $HOME 不存在时，才回退使用 $VIM。参见 _vimrc 。 标签文件格式变更 tags-file-changed
标签文件 (tags) 的字段仅允许制表符分隔。方便支持文件名包含空格，同时保持 Vi 兼 容性。旧版 Vim 允许任意空白符分隔字段。如果现有标签文件字段之间不是单一制表 符，可打开标签文件并执行: :%s/\(\S*\)\s\+\(\S*\)\s\+\(.*\)/\1\t\2\t\3/ 选项变更 options-changed
'errorfile' 缺省值由 "errors.vim" 改为 "errors.err"。原因是 ".vim" 后缀应当仅 用于 Vim 脚本。 :make 不再使用 'errorfile' 选项，防止手动保存的错误文件被该命令输出覆盖。现 改用 'makeef' 选项，可生成唯一文件名，避免多个并发 :make 命令互相覆盖文件。 开启 'insertmode' 后，额外行为变化: - 普通模式下按 <Esc> 进入插入模式。 - 插入模式下按 <Esc> 不会退出插入模式。 - 执行 `:set im` 时，立刻切换至插入模式。 当 'fileformat' (旧名 'textmode') 和缓冲区初始格式不一致时，Vim 会判定缓冲区已 修改。 插入模式下 CTRL-B 移除 i_CTRL-B-gone
编译开启 +rightleft 特性时，曾经可用 CTRL-B 切换 'revins' 选项。但部分用户在 按 CTRL-V / CTRL-N 时误触 'B' 键，触发后很难发现如何恢复。 切换 'revins' 可通过如下映射轻易实现，因此决定移除该快捷键。仍可用 CTRL-_ 完成 切换 i_CTRL-_ 。 :imap <C-B> <C-O>:set revins!<CR>

新 特 性 new-5

语法高亮 new-highlighting
Vim 新增一套高度灵活的机制，几乎可以为任意类型文件提供高亮。参见 syntax 。概 要: :syntax on 可为语法高亮设置颜色与属性；'highlight' 选项的 ':' 场景的其他高亮项同样适用。 所有高亮项都会绑定一个高亮组，由该组定义渲染样式。参见 :highlight 。缺省配色 已优化。 可使用 "Normal" 组设置彩色终端的缺省前景与背景色；GUI 版本还能通过该组指定字 体。 "2html.vim" 脚本可将带语法高亮的文件转为 HTML，颜色与 Vim 内显示完全一致。借助 HTML 查看器还能彩色打印文件。 内置脚本语言 new-script
新增若干命令与表达式求值器，可编写简洁且功能强大的脚本。包含 ":if"、":while" 等命令。表达式可处理数值与字符串。可使用 '=' 寄存器直接插入表达式计算结果。参 见 expression 。 Perl 与 Python 支持 new-perl-python
Vim 可通过 :perldo 、 :perl 等调用 Perl 代码。参见 perl 。补丁由 Sven Verdoolaege、Matt Gerassimoff 贡献。 Vim 可通过 :python 、 :pyfile 等调用 Python 代码。参见 python 。 这两项功能均需要编译时开启才可用。 Win32 GUI 版本 added-win32-GUI
GUI 已移植到 Windows 95 和 NT。Windows 用户现在可以拥有 X11 GUI 的全部特性。 gui-w32 同时修复 Win32 控制台版在 Windows95 下运行的问题，该系统原生控制台支持一直不 佳。 另有支持 OLE 自动化接口的版本。 if_ole.txt 可通过 VisVim DLL 将 Vim 集成进 Microsoft Developer Studio。 可使用 Borland C++ 编译生成 gvim 的 DLL 版本 (Aaron)。 VMS 版本 added-VMS
Vim 现已支持 VMS 系统。移植工作由 Henk Elbers 完成。 该版本测试尚不充分，但应当可以运行。 抱歉，暂无配套文档！ BeOS 版本 added-BeOS
Vim 可运行在 BeOS 系统 (含 BeBox)。 (Olaf Seibert) 参见 os_beos.txt 。 Macintosh GUI 版本 added-Mac
Vim 现已支持 Macintosh。 (Dany St-Amant) 测试尚不充分，请谨慎使用！ 参见 os_mac.txt 。 更强的 Vi 兼容性 more-compatible
实现了真正的 Ex 模式。可通过 Q 命令进入，或直接以 "ex" 或 "gex" 程序名启动。 Ex-mode 多级撤销现在始终可用，Vi 兼容模式下同样支持。'cpoptions' 包含 'u' 标志位时， CTRL-R 可用于重做或重复撤销 (类似 Nvi 里 "." 的行为)。 从标准输入读取 read-stdin
使用 "-" 命令行参数时，Vim 从标准输入读取文本。可放在管道末端使用: grep "^a.*" *.c | vim - 参见 -- 。 正则表达式模式 added-regexp
新增原子匹配次数范围写法: "\{a,b}"。 /\{ 新增 "最短匹配" 正则: "\{-}" (Webb)。 /\{- 新增 "\s"，匹配空白字符。可替代 "[ \t]"。 /\s 新增 "\S"，匹配非空白字符。可替代 "[^ \t]"。 /\S 标签重载 tag-overloaded
使用 C++ 这类语言时，同一个标签名可能对应多个标签。新增命令，可跳转至任意一个 重载标签: :tselect 列出匹配标签，并选择跳转。 :stselect 同上，同时分割窗口。 g_CTRL-] 对光标下的单词执行 :tselect 。 执行 ":ta {标签名}" 存在多条匹配结果后: :tnext 跳转到下一个匹配标签。 :tprevious 跳转到上一个匹配标签。 :trewind 跳转到第一个匹配标签。 :tlast 跳转到最后一个匹配标签。 :tag 命令现支持通配符。对标签进行命令行补全时，末尾可启用大小写不敏感匹配。 新增命令 new-commands
:amenu 为所有模式定义菜单；插入模式会自动插入 CTRL-O，可视模式插入 ESC，命令行模式插入 CTRL-C。用于内置缺省菜单与语法菜单。 :augroup 设定后续自动命令所属组。可对自动命令分组，支持删除指定组。 :crewind 跳转至第一条错误。 :clast 跳转至最后一条错误。 :doautoall 对所有已加载缓冲区执行自动命令。 :echo 输出表达式参数，可展示包含变量的消息。 :execute 执行表达式参数，可动态拼接 Ex 命令。 :hide 类似 ':close'。 :if 内置脚本语言的条件执行。 :intro 显示启动欢迎信息。不带文件参数启动 Vim 时总会执行。 :let 给内部变量赋值。 :omap 为操作符等待模式建立专用映射，支持文本对象命令映射。 :redir 将消息输出重定向至文件。 :update 缓冲区已修改时才写入磁盘。 :while 内置脚本语言的 while 循环。 可视模式: v_O 列块可视模式下按 "O"，将光标移至水平对角。 v_D 列块可视模式下按 "D"，删除至行尾。 插入模式: i_CTRL-] 触发缩写展开，无需插入任何字符。 新增选项 added-options
'background' 用于选择高亮缺省配色，"syntax.vim" 依据它选取语法颜色。常根据 终端自动设置。 'complete' 设定插入模式补全行为。 'eventignore' 临时忽略自动命令。 'fileformat' 当前文件格式，替代旧选项 'textmode'。 'fileformats' 识别的文件格式列表，替代旧选项 'textauto'。 新增支持 Macintosh 格式: 单个 <CR> 作为换行符。 MS-DOS、Win32、OS/2 平台缺省值为 "dos,unix"，即使开启兼容模式 也是如此。设为空时，Unix 格式文件本就无法正常识别。 'guicursor' 设置多种模式下光标形状与闪烁。缺省在插入、替换、操作符等待模式 下自动切换光标；闪烁缺省开启。 'fkmap' 波斯语按键映射。 'hlsearch' 高亮所有匹配上一次搜索模式的文本。 'hkmapp' 音译 (phonetic) 希伯来语映射。(Ilya Dogolazky) 'iconstring' 自定义图标名，非空时生效 (5.2 版本: 字符串按本义使用，换行可生 成两行文本)。 'lazyredraw' 执行宏、寄存器或非手动输入命令时，不刷新屏幕。 'makeef' :make 使用的错误文件。"##" 会替换为唯一编号，防止多 Vim 实例 互相覆盖错误文件。Unix 缺省为 "/tmp/vim##.err"；Amiga 则为 "t:vim##.Err"；其他平台则为 "vim##.err"。 'matchtime' 开启 'showmatch' 时，括号配对提示的显示时长，单位 0.1 秒，风格 类似 Nvi。 'mousehide' GUI 版本输入文本时隐藏鼠标指针。 'nrformats' 定义 CTRL-A、CTRL-X 识别数值的基底。缺省: "hex,octal"。 'shellxquote' 给整条外壳命令 (含重定向) 增加外层引号。 'softtabstop' 让输入体验等效于 'tabstop' 设为此值，但不修改 'tabstop'。例 如，'ts' 可保持为 8，同时按 <Tab> 得到 4 个空格。 'titlestring' 窗口标题字符串，非空时生效 (5.2 版本: 字符串按本义使用，换行可 生成两行文本)。 'verbose' 日志详细等级。可查看实际加载的 .vimrc、.exrc、.viminfo 等初始 化文件，以及执行的自动命令。也可通过 -V 命令行参数设置。 新增命令行参数 added-cmdline-args
-U 指定加载的 gvimrc 文件，对应 vimrc 的 -u 。 -V 设置 'verbose' 选项，示例: "vim -V10"。 -N 以非兼容模式启动。 -C 以兼容模式启动。 -Z 以受限模式启动，禁止外壳命令；调用 "rvim" 程序名也等效。 -h 显示帮助信息并退出。 其他新增 added-various
