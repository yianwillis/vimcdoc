1. 简介 tab-page-intro

一个标签页容纳一或多个窗口。标签页间可快速切换，用于维护多套窗口布局，每套窗口 处理不同任务。 Vim 窗口顶部 (即标签栏或标签页行) 通常会显示一组标签，每个标签页对应一个标签。 鼠标点击标签即可跳转到对应标签页。下面还会介绍标签页间跳转的其他方式。 绝大多数命令仅作用于当前标签页，包括 CTRL-W 命令、 :windo 、 :all 和 :ball (但可搭配 :tab 修饰符跨标签页执行)。下面会列出能处理其他标签页的命 令。 标签页也是临时编辑缓冲区而无需修改当前窗口布局的好方法。新建标签页完成工作，用 完直接关闭标签页即可。

3. 其他项目 tab-page-other

tabline-menu GUI 标签栏自带弹出菜单。可通过鼠标右键激活。其中菜单项包括: 关闭标签 关闭鼠标指针所在标签页。指针不在任何标签上则关闭当前标 签页。 新建标签 新建打开空缓冲区的标签页。新标签页出现在鼠标指针左侧。 打开标签... 类似 "新建标签"，但额外弹出文件选择器，打开指定文件。 比较模式在不同标签页内分别进行。在一个标签页内可查看若干文件的差异。而在另一个 标签页内对另一组文件进行比较。 标签页局部变量使用 "t:" 前缀。 tabpage-variable 目前仅有一个标签页局部选项: 'cmdheight'。 tabnew-autocmd TabLeave 和 TabEnter 自动命令事件可用于在标签页切换时执行用户操作。事件触发顺 序随操作不同而变化。新建标签页时，相当于先在同一缓冲区上新建窗口，再切换到其他 缓冲区。例如， :tabnew 会依次激活: WinLeave 离开当前窗口 TabLeave 离开当前标签页 WinEnter 进入新标签页内窗口 TabEnter 进入新标签页 BufLeave 离开当前缓冲区 BufEnter 进入新建空白缓冲区 而切换到其他标签页时，事件顺序则是: BufLeave WinLeave TabLeave TabEnter WinEnter BufEnter

4. 设置 'tabline' setting-tabline

'tabline' 选项设置非 GUI 标签栏的外观。GUI 标签栏存在时不使用该选项。 'showtabline' 选项指定标签栏显示的时机: 永不显示、多于一个标签页时显示、总是显 示。 标签栏用 hl-TabLine 、 hl-TabLineSel 、 hl-TabLineFill 高亮组分别指定普通标 签、当前选中标签、标签栏空白区域。 包含已修改缓冲区窗口的标签页会用 "+" 标记。同时显示标签页内窗口总数。例如 "3+" 代表标签页内有三个窗口，其中至少一个缓冲区已修改。 有多个标签页存在且启用 'mouse' 时，最右侧会出现 "X" (关闭按钮)。 'tabline' 选项自定义标签栏的外观。实现并不简单，为此以下给出一例。 基础语法见 'statusline' 选项。'tabline' 和 'tabpanel' 选项使用相同项目。还可配 套使用 tabpagebuflist() 、 tabpagenr() 和 tabpagewinnr() 函数。 因为标签页数量可变，选项必须使用表达式写法，形如: :set tabline=%!MyTabLine() 然后定义 MyTabLine() 函数，以列出所有标签页的标签。一种方便的做法是分两部分实 现。一部分遍历所有标签页，定义标签显示方式。另一部分具体实现标签页的标签获 取。 function MyTabLine() let s = '' for i in range(tabpagenr('$')) " 选择高亮组 if i + 1 == tabpagenr() let s ..= '%#TabLineSel#' else let s ..= '%#TabLine#' endif " 设置标签页号 (用于鼠标点击) let s ..= '%' .. (i + 1) .. 'T' " 调用 MyTabLabel() 获取标签 let s ..= ' %{MyTabLabel(' .. (i + 1) ..
